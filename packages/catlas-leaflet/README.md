# @catlas/leaflet

Shared React and Leaflet components for Catlas maps.

Import the feature marker and label styles once in the consuming application:

```ts
import "@catlas/leaflet/styles.css";
```

## Development

- Install dependencies:

```bash
vp install
```

- Run the unit tests:

```bash
vp test
```

- Build the library:

```bash
vp pack
```
